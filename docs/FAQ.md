# FAQ

## 能恢复所有已经删除的说说吗？

不能。恢复依赖 QQ 空间仍然保留并允许当前账号访问的互动数据。以前有点赞、评论、回复的说说更值得尝试。

## 删除很多年的说说还能恢复吗？

有可能，但不能保证。关键不是“几年”，而是相关互动记录现在是否还存在。

## 没人点赞也没人评论的说说呢？

如果没有任何可利用的互动痕迹，而且主内容也已被服务器删除，通常没有可重建的数据来源。

## 会不会把我的 QQ 密码上传？

macOS 移植层没有自己的服务器。登录发生在内嵌 QQ 空间页面，登录状态保存在本地 Electron session。不要把 Cookie 或调试数据公开上传。

## M1 / M2 / M3 / M4 怎么选？

下载文件名带 `arm64` 的 DMG。

## Intel Mac 怎么选？

下载文件名带 `x64` 的 DMG。

## 为什么提示“无法验证开发者”？

从 `v4.0.0-mac.2` 开始，公开构建已经使用 ad-hoc code signing，并在 GitHub Actions 中执行 `codesign --verify --deep --strict` 校验。

但项目目前没有使用付费 Apple Developer ID 进行 notarization，因此 Gatekeeper 仍可能在第一次启动时提示开发者无法验证。可在 Finder 中右键 App → 打开，或前往“系统设置 → 隐私与安全性 → 仍要打开”。

## 为什么提示“应用已损坏”？

请先确认下载的是 `v4.0.0-mac.2` 或更新版本。旧的 `mac.1` Apple Silicon 包存在签名问题，已经被新版替代。

如果新版仍出现同样提示，请在 GitHub Issues 中附上 macOS 版本、Mac 芯片型号和错误截图，方便进一步定位。

## 为什么安装包这么大？

桌面版基于 Electron，并且包含离线备份、档案浏览以及相关前端资源，因此比原生小工具更大。

## 能备份别人的空间吗？

工具不会绕过 QQ 的访问权限。请仅备份你有权访问和保存的内容。

## 和上游 Windows 版是什么关系？

核心 QQ 空间采集、导出和删除说说恢复逻辑来自 `salt-fishes/qzone-archiver` v4.0.0。本仓库主要增加 macOS 打包和平台行为适配。

## 收费吗？

不收费。代码公开，遵循 Apache-2.0 许可。
