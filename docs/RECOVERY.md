# 已删除 QQ 空间说说恢复原理

## 它为什么有机会恢复已经删除的说说？

QQ 空间的一条说说被删除以后，主说说列表里通常已经看不到它了。

但这条说说过去如果产生过互动，例如：

- 好友点赞
- 好友评论
- 评论回复
- 与该内容相关的互动通知

部分互动记录可能仍然通过 QQ 空间相关接口被返回。

上游 `qzone-archiver` 的恢复逻辑会利用这些仍然存在的互动数据，尝试还原与已删除说说有关的信息。

## 什么情况更值得尝试？

成功机会通常取决于服务器端还剩下多少可访问数据。

更值得尝试的情况：

- 说说以前有点赞
- 有评论或回复
- 删除时间较晚
- 互动通知仍然存在

很难或无法恢复的情况：

- 从来没有任何互动
- QQ 已经完全清理相关数据
- 账号本身没有权限读取对应内容
- 互动记录只剩极少信息，无法重建正文

## “恢复”并不等于服务器级数据恢复

这个工具不会：

- 破解 QQ 服务器
- 绕过账号权限
- 从本地硬盘扫描曾经浏览过的网页缓存来“猜”内容
- 凭空生成不存在的旧说说

它做的是：**整理 QQ 空间仍然向当前登录账号暴露的残留历史数据。**

因此页面上使用“尝试恢复”而不是“100% 恢复”。

## 数据来源

macOS port 没有重新实现 QQ API 或删除说说恢复算法。

核心逻辑来自：

- `salt-fishes/qzone-archiver` v4.0.0
- upstream commit `63967a184b44ea3eaf339f0abac72bb5244c0a75`

本项目只增加 macOS 桌面打包和平台适配，使同一套上游恢复/备份流程能够作为 Mac App 运行。
