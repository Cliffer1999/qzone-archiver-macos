# 隐私说明

QZone Archiver for macOS 的平台移植层不提供云端账号系统，也没有自己的数据服务器。

## 本地保存的内容

应用可能在你的 Mac 上保存：

- QQ 空间登录 session / Cookie
- 应用设置
- 备份进度状态
- 你选择导出的 QQ 空间内容
- 下载的图片与视频

这些数据用于维持登录状态和完成本地备份。

## 不应该上传到 GitHub 的内容

请不要公开：

- `p_skey`
- `skey`
- QQ Cookie
- 私人 QQ 空间完整备份
- 包含个人信息的调试日志
- 私人照片 / 视频

## 网络请求

QQ 空间采集逻辑来自上游 `salt-fishes/qzone-archiver`。为了读取你有权访问的 QQ 空间内容，应用需要与 QQ / QZone 的相关网络服务通信。

macOS port 本身没有新增 analytics、广告 SDK 或远程数据收集服务器。

## 权限

请仅使用本工具处理：

- 你自己的账号；或
- 你明确获得授权访问和备份的内容。

本项目不会绕过 QQ 空间原有访问控制。
